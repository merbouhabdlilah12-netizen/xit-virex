# XIT VIREX Flutter starter

This is a Flutter app starter for Android and iOS using the supplied blue dragon logo.

## Included
- Arabic RTL interface
- Black / electric-blue theme
- Dragon logo and XIT VIREX branding
- Duration selection (hour, day, lifetime)
- Key input and activation feedback (UI only; no real validation)
- Interactive info, notification, notes, share, about, and support buttons

## Run
1. Install Flutter SDK and Android Studio / Xcode.
2. Extract this archive.
3. From this folder run:
   `flutter pub get`
   `flutter run`

To build Android:
`flutter build apk --release`

To build iOS (requires macOS and Xcode):
`flutter build ios --release`

## Important
Actual key verification, user accounts, admin panel, and remote configuration require a backend/API.
This starter does not modify games or bypass game security.
